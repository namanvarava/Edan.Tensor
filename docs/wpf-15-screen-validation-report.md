# EDAN.Tensor WPF 15개 화면 검증 결과

- 검증일: 2026-11-16 (Asia/Seoul)
- 대상 앱: `EDAN.Tensor.Desktop.exe`
- 대상 창: `EDAN.Tensor`
- 검증 방식: Windows UI 자동화로 WPF 창을 활성화하고 화면 레지스트리 항목을 직접 선택한 뒤, 화면 코드·제목·입력 영역·액션 버튼의 렌더링을 확인
- API 상태: 미연결 (`API 연결 전` / 일부 화면은 `Tenant 선택 전`)

## 결론

15개 화면 모두 화면 레지스트리에서 선택할 수 있었고, 선택 후 해당 화면의 코드와 제목이 표시되었습니다. 모든 화면에서 Request DTO 입력 영역과 화면별 액션 영역이 렌더링되는 것을 확인했습니다.

이번 검증은 UI 탐색·렌더링 검증 범위입니다. API 연결, 실제 조회/생성/수정/재시도/외부 전달과 같은 서버 상태 변경은 수행하지 않았습니다.

## 공통 UI 증거

직접 관찰한 WPF 접근성 트리와 화면 캡처에서 다음 공통 요소를 확인했습니다.

- 창 제목: `EDAN.Tensor`
- 좌측 화면 레지스트리: 15개 화면 코드와 화면명이 순차적으로 노출
- API URL 입력: `https://localhost:5001`
- Tenant ID/Bearer Token 선택 입력
- 화면별 상태 표시: 초기에는 `API 연결 전`, 일부 화면은 `Tenant 선택 전`
- 검색어, 페이지, 페이지 크기, 대상 ID 입력 영역
- 구조화된 Request DTO 입력과 고급 Request DTO JSON 입력
- Idempotency/Replay 키 및 최근 결과 ID 영역
- `새로 고침`, `API 명령 실행` 및 화면별 명령 버튼
