# EDAN 전역 업무 용어·약어 확정 사전

- 문서 상태: **표준 확정**
- 표준 버전: 1.0
- 확정 기준일: 2026-11-15
- 적용 범위: EDAN Tensor 및 후속 EDAN 제품군의 전 업무 모듈
- 적용 DB: SQLite, Oracle, SQL Server, PostgreSQL
- 기준: 대표 개념은 전역 단일 약어를 사용하며 모듈별 약어 네임스페이스를 두지 않는다.

## 1. 확정 범위

## 3. 약어 규칙

1. 대표 약어는 영문 소문자 3자를 기본으로 한다.
2. 3자 약어가 다른 대표 개념과 충돌하면 의미가 분명한 4자 약어를 사용한다.
3. 최종 약어는 전역에서 유일해야 한다. 모듈별·DB별 중복을 허용하지 않는다.
4. 관계 용어·동의어·표기 변형에는 독립 약어를 발급하지 않는다.
5. 기존 약어는 레거시 매핑으로 보존하고 신규 설계에는 확정 대표 약어만 사용한다.
6. SHA-256 등 외부 표준에서 고정된 알고리즘·기술 식별자는 대표 업무 약어와 별도 기술 식별자로 관리한다.
7. 물리 컬럼명은 확정 대표 약어를 조합해 작성한다. 식별자·코드·이름·상태·여부 등 속성 토큰도 이 사전의 확정 약어를 따른다.

## 4. 복합 조합 규칙

Created/Updated 시각, Creator/Updater, Yes/No 플래그, 정렬 번호 등 7개 항목은 독립 업무 개념이 아니라 여러 표준 토큰의 조합 규칙이다. 별도 대표 약어를 발급하지 않고 구성 규칙 CSV에서 관리한다.

## 5. 기존 287개 컬럼 인벤토리와의 관계

287개 컬럼 재매핑 CSV는 확정 사전의 적용 예시 및 후속 DB 구성 검토용 논리 매핑 자료다. 이는 실제 SQLite 파일의 물리 스키마를 변경하거나 Migration을 실행한 결과가 아니다. DB 파일 구성과 EF Core 매핑을 재검토한 뒤, 이 확정 사전을 기준으로 실제 물리 이름을 별도 결정한다.

## 6. 상태 및 변경 관리

- 본 사전의 445개 대표 개념과 약어는 EDAN 전역 명명 표준으로 확정한다.
- 업무별 상세 정의·관계 용어·소유 모듈은 제품 범위가 확장될 때 보완할 수 있다. 이때 기존 대표 약어의 의미를 변경하거나 재사용하지 않는다.
- 신규 개념은 중복·의미 충돌·3자/4자 형식을 검토한 후 새 버전으로 추가한다.
- 기존 DB·API·외부 SQL의 물리 이름은 이 문서만으로 변경하지 않는다. 실제 적용은 별도 설계·Migration으로 진행한다.
